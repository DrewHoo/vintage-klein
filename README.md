# vintage-tool-hunt dossier

Standing hunt for vintage (80s/90s) tool-brand apparel — Milwaukee Electric
Tools, Klein Tools, DeWalt, Snap-on, Mac Tools and friends — men's L/XL.

- **Page:** https://drewhoover.com/vintage-klein/ (`index.html`, GitHub Pages)
- **Registry:** `data/seen.json` — every listing ever evaluated, with verdict.
  The hunt reads this first; it is the dedupe filter.
- **Survey:** `SURVEY.md` — the 2026-10-03 market survey this hunt was seeded
  from (background; not updated per run).

Runs are driven by the `vintage-tool-hunt` skill (`DrewHoo/vintage-tool-hunt`).
